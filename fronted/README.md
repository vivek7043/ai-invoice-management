# AI Invoice Management — Frontend Scaffold

This project is a React + Vite + TypeScript frontend scaffold for an AI-powered invoice management dashboard.

Quick start:

1. Install deps:

```bash
npm install
```

2. Run dev server:

```bash
npm run dev
```

3. Open http://localhost:5173

Notes:
- Tailwind CSS is configured.
- Uses React Router and Recharts. Replace mock data in `src/mock/data.ts` with real API calls.
